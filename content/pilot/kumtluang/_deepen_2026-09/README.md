# Audit trail — 2026-09-17/18 deeper extraction + Vartian merge

Intermediate/working files from the deep-extraction pass, kept for
traceability rather than discarded. Nothing here is imported directly —
the actual live files are `by_class/kumtluang_class{1-7}_vocab.csv`,
`kumtluang_vocab_master_deduped.csv`, `kumtluang_vocab_all_with_repeats.csv`
(one level up), and `content/pilot/vartian_candidates.csv`.

**IMPORTANT — use `master_deduped_new_rows_FIXED.csv`, not
`master_deduped_new_rows.csv`.** The latter was generated by a version of
the merge script that had a bug: it pooled all 8 sources (7 Kumtluang
grades + Vartian) together when deciding which cross-grade word-repeats to
collapse for the Kumtluang master file, instead of restricting that pool
to the 7 Kumtluang grades only. This wrongly copied all 80 Vartian words
into `kumtluang_vocab_master_deduped.csv` too (1540 rows instead of the
correct 1470). It was caught by a sanity check before being reported as
done, and the live master file on disk has already been corrected using
`master_deduped_new_rows_FIXED.csv` (608 rows, Kumtluang-only). See
Addendum 9's "Correction" note in
`content/pilot/CHANGELOG_TQ_RECONCILIATION_2026-09-16.md` for the full
story. `master_deduped_new_rows.csv` (the buggy 678-row version) and
`collision_log.json`/`id_remap.csv`/`verify_dedup_flags.csv` (computed
against the buggy all-8-source pool) are kept here only as a record of
what happened, not as something to merge again.

## Files
- `class{1-7}_new_rows.csv`, `vartian_candidates.csv` — correct, already
  merged into the live by_class files and `content/pilot/vartian_candidates.csv`.
- `master_deduped_new_rows_FIXED.csv` — correct, already merged into
  `kumtluang_vocab_master_deduped.csv`.
- `master_deduped_new_rows.csv` — **buggy, superseded, do not reuse.**
- `all_dropped_exact_dupes.csv` — the 158 rows dropped as exact duplicates
  of already-catalogued words.
- `verify_dedup_flags.csv` — the possible-duplicate/spelling-variant rows
  (computed pre-fix; row content itself is still accurate, only the
  master-file row counts it was summarized against were off).
- `id_remap.csv` — old (per-agent) → final (Rails-safe, globally unique)
  candidate_id mapping for all 718 kept rows.
- `collision_log.json` — cross-file collision groups found among the 876
  raw extracted rows (still useful data; just not what actually decided
  the corrected master file's dedup, which was Kumtluang-only).
- `kumtluang_class{1-7}_deepen_report.md`, `vartian_deepen_report.md` —
  each extraction agent's own method/reasoning report. (Class V's report
  didn't survive a rate-limit cutoff; its CSV output did.)
- `deepen_bundle.zip` — the original bundle these were unpacked from.
