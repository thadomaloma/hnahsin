# Kumtluang + Diaspora Content Review Packet
_Generated 2026-09-16. Companion to `REVIEW_PACKET.md` (which covers the
original 100-word/40-sentence pilot set only). This packet covers the two
newer word sources that packet doesn't touch: the 862-word Kumtluang
extraction and the 83-word diaspora expansion list._

**How to use this packet:** same process as `REVIEW_PACKET.md` — work
group by group, fill in "Reviewer decision" (approve / change / reject)
and "Approved form/sense" per `docs/CONTENT_EDITORIAL_GUIDE.md`. A
`reject`/`change` needs a note; draft authors cannot self-approve.
`meaning_mizo`/`example_mizo` are not shown here to keep the tables
scannable — check the source CSV column for those when reviewing a row
closely.

**Priority order:** Section A (culture-sensitive) first — these need a
human culture reviewer specifically, not just a language reviewer.
Section B and C can go to a language reviewer in parallel.
